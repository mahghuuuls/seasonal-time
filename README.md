# Seasonal Time

Minecraft 1.12.2 Forge mod.

Sets how many real minutes Minecraft day and night last. With Serene Seasons, days get longer toward
summer and nights get longer toward winter.

This README is a placeholder created during project initialization. The repository-facing README is
written during Release Presentation.

## Status

Initialized baseline. No gameplay behavior is implemented yet.

## Build

```bash
./gradlew clean build
```

The distributable jar is produced in `build/libs/`.
